# NGO SURVEYS

A responsive React + Tailwind CSS prototype for illustrating a survey rewards dashboard.

## Run locally

```bash
npm install
npm run dev
```

For a production check:

```bash
npm run build
```

## Parser examples

Use one of these messages in a locked tier to test the UI:

```text
QK12345678 Confirmed. Ksh 49.00 PAID
QK12345678 Confirmed. Ksh 99.00 PAID
```

The project includes 15 survey sets, 75 questions, and four options for every question. State resets by clearing this site's local browser storage.
